# 📖 사용자 (및 관리자) 설명서 (User Manual)

**프로젝트명:** Lightkey SSO System

본 문서는 일반 사용자가 사내 시스템에 접근하기 위한 방법과, 시스템 관리자가 권한 및 연동 앱을 통제하기 위한 가이드를 제공합니다.

---

## 1. 일반 사용자 가이드 (General User)

### 1.1 최초 로그인
Lightkey SSO 시스템은 사내 시스템(Service Provider) 이용을 위한 중앙 로그인 화면을 제공합니다.
*   **접속 방법:** SSO가 연동된 사내 시스템(예: 사내 메신저, 인트라넷)에 최초 접속 시, 자동으로 Lightkey 로그인 화면으로 이동합니다.
*   **인증 수단:** 발급받은 본인의 **사번(Employee ID)**과 **비밀번호**를 입력합니다. (별도의 회원가입은 없으며, 사내 인사 데이터와 자동 동기화됩니다.)
*   **통합 허브 (대시보드):** 로그인 성공 시, 본인이 접근 가능한 **사내 연동 애플리케이션 목록**을 대시보드에서 한눈에 확인할 수 있습니다. 접근이 인가된(접속 가능) 앱을 클릭하면 해당 서비스로 즉시 인증되어 이동(SSO)합니다.

### 1.2 보안 및 계정 관리
*   **로그아웃:** 대시보드 상단의 '로그아웃' 버튼을 클릭하면, Lightkey 허브는 물론 연동된 모든 앱에서의 인증 세션이 모두 초기화됩니다(통합 로그아웃 기능). 공용 단말기 사용 후에는 반드시 명시적인 로그아웃을 수행해 주세요.
*   **계정 잠금 정책:** 올바르지 않은 비밀번호를 **연속 5회** 이상 입력할 경우, 계정이 강제 잠금 처리됩니다. 이 경우 소속 부서 IT 관리자에게 문의하여 잠금을 해제해야 합니다.

---

## 2. 관리자 가이드 (Admin Console)

`ROLE_ADMIN` 권한이 부여된 최고 관리자는 전용 어드민 페이지(`/admin`)에 접근하여 중앙 통제를 진행할 수 있습니다.

### 2.1 시스템 통합 대시보드 (`/admin`)
*   **현황 요약:** 현재 시스템에 동기화된 총 활성 사용자 수와 등록된 연동 앱(SP) 개수, 일일 인가 코드 발급량을 빠르게 파악할 수 있습니다.

### 2.2 인증 앱(Service Provider) 발급 및 통제 (`/admin/apps`)
사내의 새로운 애플리케이션에 Lightkey SSO를 연동하려면 이곳에서 식별자를 발급해야 합니다.
*   **신규 앱 생성:** "+ 신규 연동 앱 등록" 버튼을 눌러 앱 명칭과 설명, 허용 IP를 기입합니다.
*   **보안 자격 증명 (Client Secret):** 필수 사항 등록 직후 화면 중앙에 `Client ID`와 붉은색의 `Client Secret` 문자열이 발급됩니다. **단 한 번만 표시되므로, 창을 닫기 전에 반드시 안전한 곳에 복사/저장하시기 바랍니다.**
*   **IP 접근 통제 (Allowlist):** 각 앱 구동 서버가 고정 IP를 사용할 경우, "허용된 IP" 칸에 CIDR(예: `192.168.1.0/24`)을 기입하여 비인가 외부 네트워크의 접근을 원천 차단할 수 있습니다.

### 2.3 사원 계정 모니터링 및 잠금 해제 (`/admin/users`)
*   **계정 모니터링:** 시스템에 동기화된 모든 직원들의 사번, 권한(ROLE), 최종 로그인 시각을 열람합니다.
*   **비밀번호 잠금 해제:** 비밀번호를 5회 이상 오입력하여 계정이 잠금 처리된 직원의 경우, 목록 우측의 **'잠금 해제'** 버튼을 클릭하여 다시 로그인할 수 있는 상태로 즉각 복구시켜 줍니다.
